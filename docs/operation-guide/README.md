# 工件與工序設定

主視窗最上方的標頭中央切換「執行監控／工序編輯／作業紀錄」，右側為「新增／開啟…／儲存／另存新檔…」。
快捷鍵 Ctrl+N、Ctrl+O、Ctrl+S 仍可使用。SOP 名稱與版本在工序編輯的「專案」區；
有未儲存的變更時，視窗標題列的檔名後會顯示「*」。

「工序編輯」以影像為主體，分為三欄：

- 左欄：專案、全部工序（由上而下依序執行）、下一輪與順序，上下捲動。
- 中央：即時影像；下方為工件跟隨（框選參考工件、編輯跟隨區域、清除工件跟隨、定位狀態），
  以及「放大影像」「凍結畫面」與單幀預覽統計。跟隨區域編輯時會顯示取景操作。
- 右欄：作業區域清單與試跑，獨立上下捲動；區域操作列為「新增區域／編輯區域／返回即時影像」。

兩側欄寬依內容自動調整，長名稱不會被裁切。視窗太窄時，右欄內容移到影像下方。
新增、刪除、移動工序或條件時，頁面保持原本捲動位置；新增或複製的工序只捲動到剛好可見。

框選參考工件、框選新區域、移動／縮放區域或編輯跟隨區域時，左欄自動收起讓影像放大，
影像下方與右欄工具仍在原位，可直接為新區域命名；按「返回即時影像」恢復。
檢查追蹤時可按「放大影像」手動放大，按「還原版面」恢復。

## 專案與影像

填寫 SOP 名稱，選擇辨識模型；模型名稱旁直接顯示載入狀態。在主視窗上方的影像來源列選擇攝影機或影片並連線；
模型就緒前仍可編輯與儲存 SOP，單幀判定與自動試跑須等待模型就緒。

## 工件與作業區域

若安裝位置須隨工件移動，先按影像下方「框選參考工件」框選主要工件。參考工件應是安裝本體或治具，
而不是準備安裝的零件。框選時畫面會暫停；選擇清楚、紋理分散的本體特徵，
盡量排除手與工具。參考影像會隨 SOP 儲存，搬移 SOP 不必另外複製圖片。

按「編輯跟隨區域」會固定最新且定位有效的畫面；也可按「重新取景」，等想要的畫面出現後按「使用這一幀」。
取景期間不能修改區域。沒有有效定位時可等待恢復，或選「使用原始參考影像」，下方狀態會明確標示圖片來源。
在選定畫面按「新增區域」建立跟隨區域；在一般即時畫面新增的區域固定於畫面。
新畫面上的修改會換算回原始參考座標，不取代原參考圖，也不刪除既有區域或工序條件。
右欄「作業區域」平常只顯示名稱；按「編輯區域」後才顯示定位方式及「移動／縮放」「複製」「刪除」按鈕。
滑鼠停在區域上會顯示定位方式與該區域條件本幀是否成立。
編輯時拖曳框內移動、拖動角點縮放，Esc 取消當次拖曳；「復原區域」「重做區域」保留修改歷史。
按「返回即時影像」恢復影像，觀察區域是否正確跟隨。

區域可供多道工序、完成條件、違規條件與重置條件共用。改名會同步更新引用；
仍被條件引用的區域不能直接刪除，請先調整引用。

## 工序與判定

開啟 SOP 時，工序清單保留編號、名稱與拖曳把手，可直接改名或調整順序。
滑鼠停在工序名稱列會顯示說明、完成條件、判定方式、觀察時間、成立比例、超時與違規設定。
按上方「編輯」進入整體編輯模式，再按「完成編輯」回到清單。
一般模式新增或複製工序時，只有新工序開啟個別編輯，其餘維持簡潔清單。

編輯中的工序依序排列：

1. 工序列：編號、名稱、「展開／收合」；下一行為「上移、下移、複製、刪除」與「試跑」。
2. 說明：給作業員的說明，多行時自動加高。
3. 完成：判定方式（全部成立／任一成立）、觀察、成立比例、超時、最短工時，兩兩對齊排列；下面每條完成條件一個區塊。
4. 違規：判定方式、觀察、成立比例（可沿用完成）；下面每條違規條件一個區塊。
5. 單幀預覽：本幀完成與違規條件的判定結果，以及正式判定需要的時間與比例。

每個條件區塊標示「完成條件 1」等名稱與本幀結果，欄位固定為三行：物件／狀態、區域／數量、
信心／區域內，同一道工序的條件上下對齊；條件多時依序往下排列。
「新增完成條件」「新增違規條件」與「復原刪除」位於各自條件下方。
不適用的欄位在原位置顯示原因：消失條件顯示「需為 0」，整個畫面顯示「不適用」，原數值仍保留。
本幀未成立或無法判斷時，該條件下方顯示原因，例如信心度不足或位置無法確認。
缺少類別或區域的設定會直接顯示問題，不會偷偷替換為其他值。

- 全部成立：同一道工序的所有條件都符合才累積完成。
- 任一成立：有一個可判斷的條件符合即可；設定錯誤仍須修正。
- 沒有完成條件：此工序明示為人工確認，執行時由操作員確認。
- 違規條件：獨立選擇全部或任一，觀察時間與比例可沿用完成規則或自行設定。

觀察時間與成立比例共同過濾閃爍；例如觀察 1 秒、成立比例 80%，
需達到整個觀察期間與比例要求，並非看見一次物件就完成。
工序的超時、最短工時與違規規則保留原有 NG 判定。

## 預覽與正式判定

單幀預覽與正式執行呼叫同一個判定函式：完成／違規條件、全部／任一、最低數量、信心度、
區域比例與定位檢查完全相同。正式執行無法判斷而暫停累積的影格，預覽同樣顯示「無法判斷」。
單幀成立只代表本幀符合條件，正式執行仍需達到觀察時間與比例。

## 下一輪與試跑

全部工序下方是下一輪設定。未設定重置條件時，完成後依延遲秒數進入下一輪；
設定重置條件後，依其觀察時間與比例等待。未生效的欄位仍直接顯示並停用。

實際累積時間、比例、違規與順序事件，請使用每道工序的「試跑」或右欄試跑區的完整流程。
試跑使用目前草稿的快照與正式判定引擎，不寫入正式作業紀錄。
修改草稿、變更來源或模型、凍結影像、影像停止更新時，舊試跑結果會失效。

按標頭的「儲存」或 Ctrl+S 保存。取消或儲存失敗會保留編輯內容，修正後可重新儲存。

## 作業紀錄

上方一列提供日期、結果、關鍵字、「重新整理」「匯出 CSV…」「開啟截圖資料夾」。
左側為作業輪次與所選輪次的工序表；表格高度依資料列數，不保留大片空白。
輪次列含開始時間、結果與作業資訊，明細標題補充 SOP 版本與模型。
右側為 16:9 歷史截圖：選擇工序或警報即顯示事件當下的截圖與說明；此頁不播放現在的攝影機畫面。

截圖下方為警報與定位暫停。沒有資料時只顯示一行狀態，例如「本輪無警報。」「本輪無定位暫停。」
定位暫停以次數、累計秒數與恢復狀態摘要；來源時間不完整時不估造秒數。
原始資料仍保存在 records/records.db，「匯出 CSV」依目前篩選條件輸出逐工序明細。

## grip 安裝示範

框選車把手本體為主要工件，建立左側與右側安裝區，再分別設定工序：
各安裝區出現 grip、數量至少 1。依序安裝時，各位置使用不同工序；
同時檢查多個位置時，將其條件放在同一道工序並選全部成立。

到位與鎖緊需要不同的可觀察條件。短暫定位無法確認時，失效影格不能完成工序；
恢復後的累積仍遵守引擎的定位檢查。原有跟隨演算法與正式判定規則維持不變。
