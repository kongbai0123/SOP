# 跟隨區域編輯驗證

驗證日期：2026-10-19。程式版本：2026.10.19.2；這是 v2026.10.19.1 安裝包建置之後的原始碼修正。

## 畫面及座標

右側「作業區域」操作列依序為「新增區域／編輯區域／返回即時影像」。按「編輯跟隨區域」時，使用最新、同一參考工件且定位有效的原始畫面；選幀時複製畫面及其定位矩陣，後續封包不會改變這組資料。

「重新取景」顯示即時畫面並暫停區域修改，使用者按「使用這一幀」後才固定供編輯。沒有新鮮有效定位時不允許固定；可明確選用原始參考影像。修改以選定畫面的反向仿射矩陣回寫原始參考座標，參考圖及完成／違規／重置條件保留。

## 自動驗證

完整測試執行 501 項，500 項通過、1 項略過，耗時 74.119 秒。略過項目為需另外啟用的 NSIS fixture 生命週期測試；v2026.10.19.1 實際安裝包的驗證另附於該版 Release。

新增 17 項專項測試，涵蓋：

- 取用原始新畫面及相符的定位矩陣，保留參考圖、區域與條件。
- 旋轉、縮放及平移的區域反算、儲存、復原與重作。
- 重新取景期間唯讀，明確選幀後不受新封包或原陣列異動影響。
- 缺少、過期、異工件、奇異及非有限定位矩陣的拒絕處理。
- 合法影像邊界的浮點誤差容忍，以及真正超界時不改資料、不加入復原歷史。
- 固定／跟隨區域切換、正式作業開始時的遲發事件阻擋、來源或 SOP 切換後清除快取。
- 返回即時畫面立即以相符定位顯示區域；不合成判定資料或自動恢復試跑。
- 編輯時釋放封包及判定物件，只保留所需影像與矩陣。

既有工序判定、紀錄耐久寫入、備份還原、表格重繪及介面／DPI 測試一併通過。

## Windows 視窗操作

以獨立的 Windows Qt 視窗、正式 Fusion／應用樣式與合成影像操作；視窗內容為 1440×900。即時影像持續更新畫面編號，原參考圖使用不同顏色及 ORIGINAL 字樣。

實際確認最新畫面凍結、重新取景、選取另一幀、拖移區域、明確切回原圖及從右側返回即時畫面。畫面來源狀態與按鈕顯示正常，返回後持續顯示新影格及區域。

正式工站的 38 輪紀錄、70 張截圖及 3 份 SOP，以唯讀內容／SHA-256 比對確認未改變。正式視窗有未儲存修改，驗證未中斷該視窗。此次不額外啟動實體攝影機或私有模型。
