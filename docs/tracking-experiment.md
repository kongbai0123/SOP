# 自適應卡曼追蹤實驗

- 基準版本：`4bbc668`，標籤 `baseline/pre-kalman-20260929`。
- 實驗分支：`codex/adaptive-kalman-tracking`。
- 基準的 88 項測試通過後才建立分支。私人 SOP、模型、攝影機設定及現場錄影仍依原有忽略規則留在本機，不包含在 Git 快照。

## 第一階段

保留每幀光流、每 15 個處理幀參考核對，以及 2% 工件外接框對角線的偏差定義。以自適應常速度卡曼取代固定權重平滑；狀態為工件四角位置及速度，使用影像實際時間戳。預測偏差增加時提高過程噪音，特徵品質下降時降低量測權重。可信絕對定位偏差超過 2% 時直接重設濾波，避免大幅移動後拖曳。

完全無有效量測時仍回傳無定位，並清除速度；再取得量測即恢復。預測只在濾波內部使用，不會單獨觸發安裝完成。時間倒退、間隔超過 0.5 秒或解析度改變均重新初始化。

這是實驗參數，不代表現場已達到 2% 真實位置精度。帶通、加速度二階差分及尚未定義的雙模差分未加入。左右類別混淆與大角度重新定位能力不由卡曼解決。

## 驗證

執行 `.venv/Scripts/python.exe -m unittest discover -s tests`。新增靜止噪音、可信位置跳變、遮擋恢復、不規則時間戳與解析度改變的測試。

現場比較應使用相同影片與 SOP，分別測量靜止框抖動、移動延遲、遮擋恢复時間及定位失敗率。單元測試的噪音降低不能等同於現場辨識改善。
