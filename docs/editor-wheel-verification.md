# 編輯器滾輪防誤改驗證

驗證日期：2026-10-19。範圍為工序編輯頁的後續原始碼修正。

## 操作規則

數值欄及未展開的下拉選單將滾輪交給所在欄的清單，即使欄位已取得焦點也不改值。
直接輸入、鍵盤及欄位小箭頭仍可修改參數；展開的選項清單、長說明及試跑日誌保留自身捲動。
新增、複製、重建或隱藏期間建立的工序與條件均自動套用。

防護在編輯頁顯示時啟用，隱藏或關閉時停止觀察全域事件；重新顯示前補齊欄位保護。

## 專項測試

`tests/test_editor_wheel_guard.py` 的 15 項測試通過，包含：

- 整數、小數欄位及其內部文字框，取得或未取得焦點時，值、SOP 與修改通知皆不變。
- 關閉及可輸入的下拉選單、完成／違規／重置條件、動態新增工序與重建區域欄位。
- 只轉送一次至最近的捲動欄；到達頂端或底端也不改值、不帶動另一欄。
- 保留角度與像素位移、手勢階段、反向標記、裝置、時間戳及小數座標。
- 正常文字輸入、鍵盤、小箭頭、展開選單及長文字區操作。
- 顯示、隱藏、關閉、重新顯示及銷毀；隱藏期間新增的欄位重新顯示後仍受保護。

另外使用 `QTest.wheelEvent(QWindow)` 的原生視窗輸入路徑，確認滾輪不會搶走另一欄的焦點，
也不會提交尚未確認的數值。停用焦點保護的對照組能重現誤提交，修正版保持焦點、文字及值不變。
單純以 `sendEvent` 送到控制項的測試無法涵蓋這種原生焦點行為。

完整回歸執行 516 項，515 項通過、1 項略過，耗時 116.983 秒。
略過項目為需另行啟用的 NSIS 安裝生命週期測試。紀錄頁持續通知的刷新測試維持原有時間門檻並通過；
工序判定、紀錄寫入、備份還原及既有介面回歸一併通過。

## Windows 視窗操作

以 Windows Qt 視窗、正式 Fusion／應用樣式及合成 SOP 操作，起始有 8 道工序及 15 個區域。
在未選取及已選取的數值欄、左右欄未展開選單上實際滾動，確認僅對應側欄位移；
展開物件選單後僅捲動選項。新增一道工序、兩個條件後，再操作新欄位，SOP 雜湊與修改通知均保持不變。
生命週期修正後另開新視窗複驗左右欄、焦點及內容不變。

高精度／觸控板資料以 Qt 事件驗證，沒有額外使用實體觸控板、攝影機或辨識模型。
正式工站的紀錄、70 張截圖及 3 份 SOP 以唯讀內容／SHA-256 比對確認未變更。

## 隱藏頁面事件成本

保留 50 個已關閉頁面、向無關控制項送出 1,000 個事件的隔離測量中，持續全域監聽的對照組
產生 50,000 次過濾器呼叫，中位耗時 82.45 ms；修正版隱藏時為 0 次、0.24 ms。
重新顯示一頁會恢復一次監聽，關閉後歸零。這是事件成本測量，不代表影像辨識 FPS 的提升。
